# CHDP-DIFF

Recognition of Newly Added Chinese Herbal Decoction Pieces via Before-and-After Image Difference.

![CHDP-DIFF overview](assets/paper_overview.png)

Online demo: https://dart-into.github.io/CHDP-DIFF/

The online demo shows before-and-after image pairs with precomputed local pipeline outputs.

## Abstract

Recognizing newly added Chinese herbal decoction pieces is necessary for dispensing verification, but practical container images contain many categories and subtle inter-class differences. Moreover, the maintenance of large labeled datasets incurs considerable expense, especially when new categories are frequently introduced.

To address this problem, this study proposes a before-and-after image difference method for recognizing newly added pieces in dispensing containers. The method uses two images of the same container, captured before and after the decoction pieces are added. Block roughness analysis first crops the main decoction-piece region, and Dense SIFT-PCA registration aligns the image pair. Structural, color, and texture responses are then fused into an integrated difference map, from which candidate regions are generated by adaptive thresholding and morphological processing. A trained classification model predicts local patches within these regions, and majority voting gives the final category.

Experiments on 172 dispensing-container image pairs from 10 categories achieved 94.19% accuracy.

## Online Demo

The GitHub Pages web demo is intentionally static:

- before-and-after image pairs are included.
- RegionSIFT + SSIM localization results were precomputed with the local Python pipeline.
- The displayed classification labels and confidence values come from the local Swin checkpoint output.


This choice keeps the public demo stable. GitHub Pages cannot run the Python pipeline directly, and the earlier ONNX/WASM browser model produced lower-quality demo results after conversion.

## Local Preview

From this folder:

```bash
python -m http.server 8080
```

Open:

```text
http://127.0.0.1:8080
```

Do not open `index.html` directly from the filesystem; browser security blocks JSON/image fetches from `file://`.
